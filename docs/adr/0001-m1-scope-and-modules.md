# M1 scope, модули и клиент/реле

Дата: 2026-09

## Контекст

Нужен проверяемый MVP суверенной P2P-звонилки на базе задела NoCloud, без расползания в чат/DHT/десктоп. Новым разработчикам нужна ясная граница: PWA ≠ реле (Node).

## Решение

1. **M1:** identity (Ed25519) + контакты QR + голос 1:1 + файлы + Telegram-like UI грубо; чат/DHT/десктоп-нода — later.  
2. **Клиент:** Vue/TS PWA, домены без циклов; задел на WebView для сторов.  
3. **Реле:** тонкий Node в `server/`; signed challenge; RAM; multi-relay задел (до 3).  
4. **Media:** один PeerConnection; P2P first; Call multi-leg; topology mesh→SFU later.  
5. **Ключи:** noble Ed25519; master/BIP39 + encrypted backup; биометрия = unlock.  
6. **Hard cut** со старыми короткими id / `C1.`.

## Почему не альтернативы

- **Чат в M1** — тормозит тест голоса/identity.  
- **Только один реле навсегда** — против цели «соединить во что бы то ни стало».  
- **Сразу Rust-нода** — лишняя стоимость до проверки контракта.  
- **Dual со старыми id** — старое было разведкой, не прод-контракт.

## Последствия

**Плюсы:** быстрый тест; понятные модули; документация для контрибьюторов.  

**Минусы:** группы/SFU и PoW ещё не в коде; UI грубый.
