# Бэклог M1 — нарезка на стори

Цель: за один заход (сессия / PR) закрывать **1–5 SP**, редко **8**.  
Всё ≥8 **обязательно** режем. Оценка относительная (Fibonacci), не часы.

## Шкала

| SP | смысл | норма за раз? |
|---|---|---|
| **1** | крошечный контракт / тест / правка | да, можно пачкой 2–3 |
| **2** | маленький модуль с тестами | да |
| **3** | типичная стори «домен + тесты» | да, идеал |
| **5** | домен + тонкий UI или серверный кусок | да, верхняя норма |
| **8** | уже крупно — лучше 2×3–5 | только если не делится |
| **13+** | эпик — не брать целиком | нет |

**DoD стори:** `vp check` + тесты стори зелёные; контракт модуля не ломает соседей; короткий note в PR.

**Порядок:** сверху вниз по эпикам (зависимости).

## Что сознательно не дробим дальше (уже ок)

- Отдельные тесты chunk/folder/opfs — уже зелёные, не эпик M1.
- Видео / screen share / SFU / DHT / чат / PoW — **вне M1**, отдельные эпики потом.
