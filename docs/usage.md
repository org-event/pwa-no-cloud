# Как пользоваться NoCloud

NoCloud ставится как PWA. Файлы идут напрямую между устройствами по
WebRTC, не через облако. Сервер нужен только чтобы познакомить клиентов
и, при жёстком NAT, как свой TURN.

## Установка

Опубликованная сборка: https://org-event.github.io/pwa-no-cloud/

Откройте ссылку в Chrome, Safari или Edge и выберите «Установить
приложение» / Add to Home Screen. После установки оболочка открывается
офлайн. Signaling и TURN задаются в приложении (экран «Серверы»),
не на домене Pages.

Локально: соберите и откройте по HTTPS или `localhost`.

## Режим A — вручную, без сервера

1. Пресет **Вручную + STUN Google**.
2. На первом устройстве «Создать приглашение», скопировать текст или QR.
3. На втором — «Присоединиться», вставить текст, «Принять текст».
4. Ответ вернуть первому устройству. Канал открыт, когда есть Ping.

Работает в одной Wi‑Fi часто даже без интернета. Если ICE пишет, что
прямой путь закрыт NAT — нужен режим C.

## Режим B — одна локальная сеть

1. На компьютере: `vp build && node server/index.js`.
2. Оба устройства открывают `http://<lan-ip>:8000`.
3. Пресет **Локальная сеть**, одно имя комнаты, «Войти в комнату».
4. Канал открывается без QR.

## Режим C — разные сети

Пресет **Интернет: STUN Google (без TURN)** или **Свой сервер**.
Чужой открытый TURN не подставляем. Если NAT жёсткий, укажите свой
релей: [turn.md](./turn.md). Успех через TURN видно как
`сейчас путь = relay`.

## Файл и папка

Когда канал открыт:

- **Отправить файл** — получатель жмёт «Принять файл».
- **Отправить папку** — одно согласие на всё дерево, прогресс `3/40`.
- **Пауза / Продолжить** — не сбрасывает уже принятые чанки.
- Если канал оборвался, соединитесь снова и отправьте тот же файл:
  получатель докачает с курсора.

Входящие лежат в приватном OPFS origin. «Прочитать» показывает текст,
«Удалить» убирает запись.

## Уведомления и «Поделиться»

После «Принять» браузер может спросить разрешение на уведомления.
Когда файл дошёл, придёт «Файл получен».

Если PWA установлено, из другого приложения можно «Поделиться» в
NoCloud. Сначала соединитесь с пиром, затем поделитесь файлом.

## Если не соединилось

Смотрите строку ICE, не сырой SDP. Нет STUN/TURN — только локальные
адреса. Есть STUN, но fail — NAT закрыл прямой путь, нужен свой TURN.
TURN задан, а relay не появился — проверьте URL, логин и пароль.
