# Third-party agent skills

This repository vendors copies of third-party agent skills under `.agents/skills/`.

## mattpocock/skills

- Source: https://github.com/mattpocock/skills
- License: MIT (Copyright (c) 2026 Matt Pocock)
- Installed via `npx skills@latest add mattpocock/skills` (see `skills-lock.json` and `scripts/install-agent-skills.sh`)
- Skills present: ask-matt, domain-modeling, grill-with-docs, grilling, implement, setup-matt-pocock-skills, to-spec, to-tickets, triage, wayfinder

## OpenSpec workflow skills

- Skills: openspec-propose, openspec-explore, openspec-apply-change, openspec-update-change, openspec-archive-change, openspec-sync-specs
