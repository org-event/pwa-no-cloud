# Идеи горизонта (суть)

Автономная идентичность и P2P-звонилка — не «логин в облаке».

1. ID создаётся локально (как кошелёк), без запроса «свободен ли» у центра.
2. Независимые реле; пользователи с разных узлов связываются по желанию.
3. Можно передать «иди на этот сервер» / согласовать узел на пару.
4. После смены реле — найтись снова (прямой обмен + позже DHT/редиректы).
5. Регистрация на любом найденном реле; пучок запасных; клиент роутит сам.
6. Цель: личная P2P-звонилка (WebRTC) + свои STUN/TURN.
7. К ключу — имя и аватар; QR «это я»; пересылка чужого контакта.
8. Локальный ренейминг контакта важнее глобального ника.
9. Переписка локально + E2EE; синк устройств — опционально (later).
10. PWA сейчас; десктоп-нода later как инфраструктура сети.

Актуальные решения и нарезка работ: [requirements.md](../requirements.md), [architecture.md](../architecture.md), [backlog-m1.md](../backlog-m1.md).
